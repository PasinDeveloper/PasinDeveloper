# Icons

`icons.json` holds the 21 brand marks used on the Tech Stack card: one 24x24 path each, taken
unchanged from [Simple Icons](https://github.com/simple-icons/simple-icons) (files are CC0), then drawn in the page colours.

The logos stay the trademarks of their owners. Three carry their own licence and are credited in the main README:

| Icon | Licence | Source |
|---|---|---|
| PHP | CC BY-SA 4.0 | https://php.net/download-logos.php |
| Git | CC BY 3.0 | https://git-scm.com/community/logos |
| Yarn | CC BY 4.0 | https://github.com/yarnpkg/assets |

Ten more brands publish usage guidelines (Next.js, TypeScript, Tailwind CSS, Node.js, PostgreSQL, MySQL, Appwrite, Figma, Yarn, WordPress); check them before changing how a logo is shown.

`linkedin.path` is the outline LinkedIn icon from [Tabler Icons](https://github.com/tabler/tabler-icons) (MIT, (c) Pawel Kuna), used on the Connect card because Simple Icons no longer includes LinkedIn.
